ИСПРАВЛЕНИЕ КНОПКИ СОЗДАНИЯ АКТА — 2026-10-20

В архиве файлы для корня репозитория GitHub Pages:
- index.html
- client.html
- sw.js
- js/master.js

Причина: в onclick-атрибуте использовался JSON.stringify(id), который для пустого ID выдаёт двойные кавычки. В HTML-атрибуте, тоже заключённом в двойные кавычки, это обрывало атрибут onclick. Поэтому кнопка визуально нажималась, но функция submitMasterAct не запускалась и текст кнопки не менялся. Исправлено безопасным аргументом в одинарных кавычках; версия ресурсов повышена до 20261020-actclick2.

Применение:
1. В репозитории https://github.com/niksonzverek-debug/remont-miniapp замените файлы по указанным путям (js/master.js находится в папке js).
2. Дождитесь завершения публикации GitHub Pages.
3. Откройте Mini App новой кнопкой из /start и проверьте кнопку создания акта.

Не меняйте настройки бота, токены, MASTER_ID и папку data. Патч не содержит секретов.
