# Remont Bot Mini App

## Установка на GitHub Pages

1. Создай репозиторий `remont-miniapp` (публичный)
2. Загрузи все файлы из этой папки
3. Settings → Pages → Source: main, / (root)
4. Через минуту форма доступна по адресу:
   https://ТВОЙ_НИК.github.io/remont-miniapp/
