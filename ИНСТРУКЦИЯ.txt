ТехСервис — исправление выбора роли и оригинальный логотип

Файлы для замены В РЕПОЗИТОРИИ remont-miniapp (ветка main, корень):
1. index.html — убрано автоматическое назначение роли мастера по ID администратора.
   Мастер открывается только по явному role=master с подписанной сессией
   либо при наличии Telegram user и явного role=master (проверку доступа обязан выполнять сервер).
   Без явной роли открывается клиентский кабинет.
2. img/remont-bt-icon.png — согласованный 3D-логотип BT, оптимизирован 512x512.

ВАЖНО: На GitHub загружать содержимое папки miniapp из архива в КОРЕНЬ
репозитория (index.html рядом с client.html; img — рядом с css и js).
Не загружать целиком папку miniapp как дополнительный вложенный уровень.

Логотип 512x512, PNG, менее 2 МБ. GitHub поддерживает PNG и этот размер.
После загрузки дождаться успешного GitHub Pages deploy.

Другие файлы проекта, сервер, БД, токены не изменяются.
Для клиента и мастера безопасность прав всё равно проверяется на API,
а не в HTML.
