ОБНОВЛЕНИЕ MINI APP — GitHub Pages

ВАЖНО: архив собран для загрузки СОДЕРЖИМОГО в корень репозитория GitHub Pages.
Внутри архива index.html и client.html лежат на верхнем уровне, рядом с папками css и js.
Не загружайте папку miniapp целиком внутрь другой папки miniapp.

1. Откройте репозиторий niksonzverek-debug/remont-miniapp.
2. Замените в корне index.html, client.html, папку css и папку js файлами из архива.
3. Сделайте Commit changes и дождитесь завершения публикации GitHub Pages.
4. Откройте форму в Telegram именно кнопкой «📝 Открыть форму» в чате с ботом.
5. В форме мастера должна отображаться подпись «версия формы 13.10.2026».
6. Проверьте: выбор техники обновляет список работ; бренд выбирается из списка; сумма форматируется; дом/квартира вводятся отдельно; геолокация запрашивается кнопкой «Получить текущую локацию».

Если подписи версии нет, GitHub Pages ещё отдаёт старую страницу или заменены не те файлы.
