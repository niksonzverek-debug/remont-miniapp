Нужно настроить подключение

Для отображения живой статистики нужен публичный HTTPS-адрес API на вашем ПК. Он не требует платного сервера, но должен быть доступен через защищённый туннель, пока бот работает.

Настройте Cloudflare Tunnel по инструкции в комплекте и укажите его адрес в miniapp/js/advertiser-config.js, затем опубликуйте Mini App.
